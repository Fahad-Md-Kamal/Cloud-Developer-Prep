# Cloud Developer Prep

A living backend/cloud interview-prep guide, built from real practice
sessions rather than a static checklist. One unified tree now — the
38-chapter manuscript plus a running practice log, cross-linked to each
other instead of living as separate parallel pages.

## Where to start

- **[Manuscript Home](manuscript/index.md)** — the full contents: 38
  chapters + appendices, organized by Part.
- **[Session Log](manuscript/session-log.md)** — a running, dated log of
  practice Q&A: what was asked, what was answered, what feedback came
  back, linking into the specific chapter each round belongs to.

## Current job-search track: Senior Python/Django

Practice work from live sessions lives as "Practice Notes" sections
inside the relevant chapter, not on separate pages:

- Mutable default arguments → [Chapter 1: Modern Python Mastery](manuscript/chapter-1.md#practice-notes-from-live-session)
- `select_related` vs `prefetch_related` → [Appendix B: Django ORM Cheat Sheet](manuscript/appendix-b.md#practice-notes-from-live-session)
- SQL window functions + practice sandbox → [Chapter 8: Database Architecture for Scale](manuscript/chapter-8.md#practice-notes-from-live-session)
- AWS gap services (ECS, Aurora RDS, DynamoDB) → [Appendix C: AWS Services Quick Reference](manuscript/appendix-c.md)
- Project stories for system-design questions → [Appendix D: Personal Project Stories](manuscript/appendix-d.md)

## A note on names

Appendix D uses generic project labels ("geospatial data platform
client", "cybersecurity risk platform client") left over from when this
