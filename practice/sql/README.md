# SQL practice sandbox

A real SQLite database to run queries against instead of reasoning about
SQL on paper. Same `employees`/`departments` shape used in the prep
site's SQL page, with enough rows (and enough ties) to make window
function edge cases show up for real.

## Setup

```bash
cd practice/sql
sqlite3 practice.db < schema.sql
```

## Use

```bash
sqlite3 practice.db
```

Optional, for readable output: `.headers on` and `.mode column` inside
the shell. `.quit` to exit.

## Files

| File | What it is |
|---|---|
| `schema.sql` | Table definitions + seed data — 4 departments, 16 employees, deliberately includes salary ties within every department. |
| `problems.md` | 8 problems, warm-up joins through `RANK`/`ROW_NUMBER`/`LAG`/`LEAD`. |
| `solutions.md` | Verified solutions — each query was actually run against this database, not hand-derived. Don't open until you've attempted the problem. |
| `practice.db` | Generated by the setup command above — not committed (see `.gitignore`), rebuild it any time. |
